# appcraftstudio

The appcraftstudio website, served by GitHub Pages.

- `index.html`: the home page, listing the apps
- `scancraft/privacy-policy/`: the ScanCraft (com.craftscans) privacy policy, the URL given to Google Play

Edit the HTML and push to `main`; Pages republishes within a minute.
- `rozana/`: Rozana Hisab (com.hisabrozana) about & pricing page
- `rozana/privacy-policy/`: the Rozana Hisab privacy policy, the URL given to Google Play
- `rozana/delete-account/`: the account-deletion page Google Play asks for
